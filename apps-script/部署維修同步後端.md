# 維修同步後端部署說明

這份說明用來把 GitHub Pages 網站的維修紀錄，改成多人共用的 Google Sheet 雲端資料。

## 已建立的 Google Sheet

資料庫名稱：

```text

```

網址：

```text
https://docs.google.com/spreadsheets/d/1IPcwCNKbCRVz9JsvQYeYhZ4qQnEPzQZza8WE081VcJ0/edit
```

分頁名稱：

```text
repairs
```

## 部署 Apps Script

1. 打開上面的 Google Sheet。
2. 點選上方選單「擴充功能」。
3. 點選「Apps Script」。
4. 把 `apps-script/Code.gs` 的內容貼到 Apps Script 編輯器。
5. 按「儲存」。
6. 點右上角「部署」。
7. 選「新增部署作業」。
8. 類型選「網頁應用程式」。
9. 設定：

```text
執行身分：我
誰可以存取：任何人
```

10. 按「部署」並完成 Google 授權。
11. 複製部署後產生的「網頁應用程式 URL」。

## 已部署過時如何更新

如果已經有 Web App URL，這次不要新增另一個網址，請更新原本部署：

1. 打開 Apps Script 編輯器。
2. 把 `apps-script/Code.gs` 的內容完整貼上。
3. 按「儲存」。
4. 點右上角「部署」。
5. 點「管理部署作業」。
6. 選目前正在使用的 Web App。
7. 點鉛筆圖示編輯。
8. 版本選「新增版本」。
9. 說明可填：`2026-06-12 JSONP repair write sync`。
10. 確認設定仍是：

```text
執行身分：我
誰可以存取：任何人
```

11. 按「部署」。

這次 `Code.gs` 已讓 `doGet` 支援 `action=upsert`，所以不同網域的 GitHub Pages 可以用 JSONP 方式新增與更新維修紀錄。

## 貼回網站

拿到 URL 後，回到 `app.js` 找到：

```js
const GAS_WEB_APP_URL = 'https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec';
```

改成你的 Web App URL。

改完後重新發佈到 GitHub Pages。

目前已啟用的 Web App URL：

```text
https://script.google.com/macros/s/AKfycbwDzpxuTFkUdQxzBEgdIzETqenKlDcKpN_AjKjG2IIRkls7BHZGNEF78lbbro-dJ2Pv/exec
```

## 完成後會得到什麼

- 對方新增維修，你這邊重新整理後看得到。
- 你標記完成，對方重新整理後也看得到。
- 維修紀錄不再只存在各自瀏覽器。
- 資料會集中存在 Google Sheet 的 `repairs` 分頁。

## 目前同步範圍

這一版只同步維修紀錄：

- 新增維修
- 讀取維修清單
- 更新未完成 / 完成狀態
- 完成紀錄保留 7 天後自動清除，避免雲端資料長期累積
- `action=health` 可檢查目前後端版本與完成紀錄保留天數
- 手機端背景同步備援：JSONP 失敗時，前端會改用隱藏表單 POST，後端已支援表單欄位格式

房客、帳單、水電等其他模組暫時不改，以免影響原本流程。
