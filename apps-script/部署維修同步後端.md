# 維修同步後端部署說明

這份說明用來把 GitHub Pages 網站的維修紀錄，改成多人共用的 Google Sheet 雲端資料。

## 已建立的 Google Sheet

資料庫名稱：

```text
Bravo House 維修紀錄資料庫
```

網址：

```text
https://docs.google.com/spreadsheets/d/1IPcwCNKbCRVz9JsvQYeYhZ4qQnEPzQZza8WE081VcJ0/edit
```

分頁名稱：

```text
repairs
```

## 部署 Apps Script

1. 打開上面的 Google Sheet。
2. 點選上方選單「擴充功能」。
3. 點選「Apps Script」。
4. 把 `apps-script/Code.gs` 的內容貼到 Apps Script 編輯器。
5. 按「儲存」。
6. 點右上角「部署」。
7. 選「新增部署作業」。
8. 類型選「網頁應用程式」。
9. 設定：

```text
執行身分：我
誰可以存取：任何人
```

10. 按「部署」並完成 Google 授權。
11. 複製部署後產生的「網頁應用程式 URL」。

## 貼回網站

拿到 URL 後，回到 `app.js` 找到：

```js
const GAS_WEB_APP_URL = 'https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec';
```

改成你的 Web App URL。

改完後重新發佈到 GitHub Pages。

目前已啟用的 Web App URL：

```text
https://script.google.com/macros/s/AKfycbwDzpxuTFkUdQxzBEgdIzETqenKlDcKpN_AjKjG2IIRkls7BHZGNEF78lbbro-dJ2Pv/exec
```

## 完成後會得到什麼

- 對方新增維修，你這邊重新整理後看得到。
- 你標記完成，對方重新整理後也看得到。
- 維修紀錄不再只存在各自瀏覽器。
- 資料會集中存在 Google Sheet 的 `repairs` 分頁。

## 目前同步範圍

這一版只同步維修紀錄：

- 新增維修
- 讀取維修清單
- 更新未完成 / 完成狀態

房客、帳單、水電等其他模組暫時不改，以免影響原本流程。
